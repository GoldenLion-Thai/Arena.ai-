      What this is
      
          
        
            
      • Every page is indexed into RAG, so it is citable in an answer alongside contracts and policies.
        • 
            
      • Revisions are immutable: an edit creates revision N+1, the old text stays readable, and the diff is shown.
        • 
            
      • Links ([[slug]], [text](wiki:slug) or a bare
              /wiki/slug) build a backlink graph in both directions.
        • 
            
      • Pages are mirrored back out to SharePoint, so nothing exists only in this system.
        • 
            
      • Each page can carry a review date; overdue reviews appear in the queue on the left.
